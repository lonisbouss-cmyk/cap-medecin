# CAP Médecin

Application gratuite de révision pour les étudiants en médecine, de la PASS/LAS à l’EDN et aux ECOS : fiches de cours, QCM corrigés, cas cliniques progressifs, mémo (valeurs normales, scores, formules), médicaments, calculateurs, méthodologie ECOS, lexique et cartes mémoire.

- Version web : https://lonisbouss-cmyk.github.io/cap-medecin/
- APK Android : https://github.com/lonisbouss-cmyk/cap-medecin/releases/download/apk/CAP-Medecin.apk

Support pédagogique : ne remplace ni les référentiels officiels ni un avis médical.
